# @price-hunter/web

React frontend for PRICE HUNTER (Phase 1).

## Develop

From the monorepo root:

```bash
npm run dev:web
```

Or from this package:

```bash
npm run dev
```

## Notes

- Feature modules live under `src/features/`
- Demonstration catalog is isolated in `src/data/demo/`
- Shared domain types come from `@price-hunter/shared`
